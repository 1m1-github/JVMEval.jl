JVM.JVMStruct — Type
JVMStruct

Mutable handle to an isolated Julia process (the "virtual machine").

Contains the ZMQ sockets, output buffers, background tasks and the underlying Base.Process. Created by startjvm.

source
JVM.closejvm! — Method
closejvm!(jvm::JVMStruct)

Close the ZMQ sockets belonging to jvm. Does not kill the process; call kill(jvm.process) yourself when you are finished.

source
JVM.eval! — Method
eval!(jvm::JVMStruct, code::AbstractString) -> String

Evaluate code inside the isolated process.

Returns "OK" on success or "ERROR" on failure. Printed output and the show representation of a non-nothing result are pushed into jvm.outbuffer. Errors go into jvm.errbuffer.

If the process has already died, it is automatically restarted before the evaluation.

JVM.readjvmbuffer! — Method
readjvmbuffer!(buffer::Vector{String}) -> String

Drain and return the contents of a buffer (normally jvm.outbuffer or jvm.errbuffer), then empty it.

JVM.restartjvm! — Method
restartjvm!(jvm::JVMStruct) -> JVMStruct

Kill the current process (if still running) and start a fresh one in the same working directory. The JVMStruct is updated in-place.

source
JVM.startjvm — Method
startjvm(path::AbstractString) -> JVMStruct

Start a new isolated Julia process whose working directory is path.

The child is launched with the same project environment as the caller (Base.active_project()). Returns a JVMStruct that can be used with eval!, readjvmbuffer!, etc.
